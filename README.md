| What | Where |

## Getting a lab notebook

Open the notebook on GitHub, click **Download raw file**, and open it in VS Code.
Or clone this repository once and run `git pull` every week:

```
git clone https://github.com/hua-intro-python-2026/course-materials.git
```

## Using AI

- Weeks 1–2: no AI.
- Week 3: AI may explain (an error, a line, a concept), not write code.
- Week 4 on: AI may write code, only against tests you wrote and committed first. Every pull request logs how you used AI.
- Exercises: AI may explain, not write.
